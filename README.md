## 🚀 How to Run

### Step 1 — Install Dependencies

```bash
pip install -r backend/requirements.txt
pip install jupyter notebook
```

### Step 2 — Run the Jupyter Notebook

```bash
cd notebook
jupyter notebook ids_model.ipynb
```

Run all cells (Cell → Run All). This will:
- Load and preprocess the dataset
- Train Random Forest + Decision Tree classifiers
- Generate evaluation charts (saved to `frontend/`)
- Save `model.pkl`, `scaler.pkl`, `label_encoder.pkl` to `backend/`

### Step 3 — Start the Flask Backend

```bash
cd backend
python app.py
```

API runs at: `http://127.0.0.1:5000`

### Step 4 — Open the Frontend Dashboard

Open `frontend/index.html` in your browser (or use VS Code Live Server).

The dashboard will:
- Show model performance metrics
- Let you input network flow features and classify traffic in real time
- Display all charts generated by the notebook
- Log all predictions with timestamps

## 📊 Results Summary

| Metric | Random Forest | Decision Tree |
|--------|--------------|---------------|
| Accuracy | ~99%+ | ~99% |
| Precision (DDoS) | ~99%+ | ~99% |
| Recall (DDoS) | ~99%+ | ~99% |
| F1-Score | ~99%+ | ~99% |

> Exact values are printed at the end of the notebook run.

**Why Random Forest?**
Random Forest was selected for its ensemble nature — it averages predictions from 100 decision trees, reducing variance and preventing overfitting. It handles the high-dimensional, correlated nature of network traffic features well, and provides feature importance scores directly useful for security analysts.

**Security Implication of Recall:**
High Recall for DDoS = fewer missed attacks (false negatives). In security, a false negative (missed DDoS) is far more dangerous than a false positive (flagging legitimate traffic), so maximizing DDoS recall is a design priority.
